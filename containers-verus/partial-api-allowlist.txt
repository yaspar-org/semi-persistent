# The one entry, added 2026-09-25 by owner decision:
#   - tagged.rs::from_repr_clean (requires an untagged repr). The unmasked
#     decode that lets the optimizer see a stored id as the value written
#     (list append 1.04x fixed / 1.03x opaque, past the pre-merge code). Its
#     only caller is the untracked InlineStore::get, where the store's
#     invariant proves the precondition. It cannot be sealed onto a
#     crate-private supertrait like DiffStoreOps: consumer crates implement
#     `Tagged` through the id macros. The total form (test the bit, refuse)
#     measured 0.95x on opaque append. Retired by a capability-token
#     parameter only this crate can mint (callable from verified code alone),
#     or by verifying the consumers.
#
# How the former floors drained (doc/future/total-api-plan.md):
#   - type-class law (map.rs::new, obeys_key_model): a conditional
#     postcondition (`obeys_key_model::<K>() ==> m.wf()`), nothing to check;
#     tagged.rs trait laws: `repr_wf(r) ==> ...` conditional contracts.
#   - unreachable receivers (DiffStore protocol methods): sealed onto the
#     crate-private supertrait `diff_store_ops::DiffStoreOps` (module
#     `pub(crate)`), so the public `DiffStore` carries only total methods.
#   - component boundary (circular_list.rs::{splice, splice_absorb}): a
